# Notes App
Мобильное приложение для ведения конспектов в цифровом формате. Разработано в рамках индивидуального цифрового проекта для университета.

## О проекте

Приложение заменяет физическую тетрадь в клетку: позволяет создавать страницы, рисовать пером, строить базовые фигуры и экспортировать конспекты в PDF.
Работает офлайн, данные хранятся на устройстве.

Целевая аудитория: студенты, школьники, преподаватели, репетиторы.

## Возможности
- Создание и удаление конспектов
- Переименование конспектов
- Мультистраничность: добавление и удаление страниц внутри одного конспекта
- Свободное рисование пером со сглаживанием штрихов
- Базовые фигуры: линия, прямоугольник, круг
- Ластик (удаление элементов касанием)
- Отмена последнего действия
- Очистка страницы
- Сетка в клетку с выделением каждой пятой линии
- Выбор цвета (6 предустановленных) и толщины (4 варианта)
- Экспорт всех страниц конспекта в один PDF-файл
- Скачивание PDF на Web, системный share sheet на Android и iOS
- Автосохранение при рисовании и при выходе из редактора

## Технологический стек

- Flutter (Dart) — единая кодовая база для Android, iOS и Web
- CustomPainter — рендеринг холста, сетки и штрихов
- Provider — управление состоянием
- shared_preferences — локальное хранение данных в JSON
- pdf и printing — генерация и распространение PDF

## Установка и запуск

### 1. Клонирование и установка зависимостей

    git clone <адрес-репозитория> notes_app
    cd notes_app
    flutter pub get

### 2. Запуск на Web 

    flutter run 

Приложение откроется в браузере. Экспорт PDF скачивает файл в папку загрузок браузера.

### 3. Запуск на Android

Подключите телефон с включённой отладкой по USB или запустите эмулятор через Android Studio. Затем:

    flutter devices
    flutter run -d <id-устройства>

Например:

    flutter run -d emulator-5554

Экспорт PDF открывает системный диалог «Поделиться» — файл можно сохранить в Files, отправить в мессенджер или распечатать.

### 4. Запуск на iOS

Требуется macOS с установленным Xcode.

    cd ios
    pod install
    cd ..
    flutter run -d <id-устройства>

### 5. Сборка релизной версии

Web:

    flutter build web

Android (APK):

    flutter build apk --release

Android (App Bundle для Google Play):

    flutter build appbundle --release

iOS:

    flutter build ios --release

## Использование

1. На главном экране нажмите «Создать» — откроется новый конспект с одной страницей.
2. В нижней панели выберите инструмент: перо, линия, прямоугольник, круг или ластик.
3. Выберите цвет и толщину.
4. Рисуйте пальцем или мышью по холсту.
5. Для добавления новой страницы нажмите «+» в верхней панели над холстом.
6. Для переключения между страницами нажимайте на их номера.
7. Кнопки в верхней панели: отменить последнее действие, очистить страницу.
8. Вернитесь на главный экран — изменения сохраняются автоматически.
9. Долгое нажатие на конспект или кнопка с тремя точками открывает меню: переименовать, экспорт в PDF, удалить.

## Технические особенности

### Нормализованные координаты

Все точки хранятся в диапазоне от 0 до 1 относительно размера холста. Это позволяет одинаково отображать конспект на экранах разного размера, корректно масштабировать содержимое при экспорте в PDF и в дальнейшем синхронизировать данные между устройствами.

### Автосохранение

Изменения записываются в хранилище с задержкой 400 миллисекунд, чтобы не выполнять запись на каждом кадре при рисовании. При выходе с экрана редактора изменения сохраняются принудительно.

### Экспорт PDF

Каждая страница конспекта выводится на отдельный лист A4. Содержимое вписано в лист с сохранением пропорций холста. Сетка и элементы рисуются через низкоуровневый PdfGraphics. Для совместимости без подключения дополнительных шрифтов заголовки страниц в PDF выводятся на латинице (Page 1, Page 2). Имя скачиваемого файла сохраняет оригинальное название конспекта.

На Web файл скачивается напрямую через Blob и ссылку download. На Android и iOS используется Printing.sharePdf, открывающий системный диалог.

## Известные ограничения

- Нет синхронизации между устройствами
- Нет авторизации
- Нет масштабирования холста жестами
- Ограниченный набор цветов и толщин
- Кириллица в заголовках PDF заменена на латиницу из-за отказа от подключения TTF-шрифтов
- На Flutter master и beta возможны предупреждения о deprecated API material.dart
